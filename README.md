# 🤖 Sobre Mim Profissional

Olá! Sou Gabriel Theodoro, um desenvolvedor Full Stack apaixonado por criar sistemas modernos, inteligentes e escaláveis.

Minha jornada na tecnologia começou através da curiosidade e rapidamente evoluiu para uma forte conexão com o desenvolvimento Back-End, Banco de Dados e Inteligência Artificial.

Atualmente curso Sistemas de Informação pela UNINOVE e possuo formação técnica pelo SENAI, construindo uma base sólida em desenvolvimento de software, arquitetura de sistemas e criação de aplicações web modernas.

Tenho experiência com desenvolvimento Full Stack utilizando tecnologias modernas como Python, Flask, JavaScript, React, Node.js e bancos de dados relacionais.

Meu foco é desenvolver aplicações tecnológicas com design profissional, alta performance e soluções inteligentes voltadas ao futuro da tecnologia.
